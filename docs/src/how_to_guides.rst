How-to Guides
=============

Overview
--------

The following guides explain individual features of the library in detail and
are aimed at users who already know the basics. They are step-by-step walk
throughs of what can be done with a specific abstraction, rather than a
reference of every function.

All of them are part of the Mitsuba 3 documentation. Since misuka is a
compatible extension to Mitsuba 3, they apply unchanged to acoustic scenes as
well.
