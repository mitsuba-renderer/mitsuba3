.. _optix-wsl2:

Mitsuba on WSL 2
----------------

misuka reuses Mitsuba 3's OptiX backend for hardware-accelerated ray tracing on
the GPU, so getting it to run under the Windows Subsystem for Linux 2 (WSL 2)
follows the exact same procedure as upstream Mitsuba. Refer to the Mitsuba guide
for the full step-by-step instructions:

`Mitsuba on WSL 2 <https://mitsuba.readthedocs.io/en/v3.9.0/src/optix_setup.html>`_
