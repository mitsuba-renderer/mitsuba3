Key Topics
==========

Overview
--------

Rather than explaining how to do things in misuka, the key topics give you
background information on acoustic rendering and in-depth information about the
concepts that misuka builds on.
The tutorials and guides link here whenever a subject deserves more depth.

:ref:`sec-acoustic-rendering` is the place to start. It covers time-resolved
sound transport, the energy-time curve that misuka records, and which parts of
Mitsuba 3 are replaced for acoustic rendering.

Because misuka is a compatible extension to Mitsuba 3, the variant overview and
the scene format are unchanged and stay documented in the Mitsuba
documentation. Both are linked below.
